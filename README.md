# N.D. Sujanth Roy & I. Mary Princy — Wedding Invitation Website

A luxury, cinematic, mobile-first digital wedding invitation website built with React 19, TypeScript, Vite, Tailwind CSS, and Framer Motion.

## 💍 Wedding Details
* **Couple:** N.D. Sujanth Roy & I. Mary Princy
* **Date:** Sunday, 15 November 2026
* **Wedding Ceremony:** 10:45 AM at Sacred Heart Church, Kilachery, Tamil Nadu
* **Wedding Reception:** 12:30 PM at Brindavan Mahal, Kilachery, Tamil Nadu

## ✨ Key Features
* **Mobile-First Experience:** Engineered for smartphones with touch-friendly interactions ($\ge 44\text{px}$) and natural one-finger scrolling.
* **Cinematic 3D Envelope Opening:** Realistic velvet burgundy envelope, debossed ivory wax seal with "S & M" monogram, 3D flap rotation, and card reveal.
* **Prominent Wedding Date (Scene C):** Immediate date presentation with dominant numeral `15`.
* **Authentic Church Photography:** Authentic iPhone 16 Pro photography of Sacred Heart Church converted to high-performance responsive WebP assets.
* **Live Dynamic Countdown:** Real-time countdown to 15 November 2026, 10:45 AM IST.
* **Verified Venue Links:**
  * [Sacred Heart Church Directions](https://maps.app.goo.gl/6XaabqdPQz4d5h2x5)
  * [Brindavan Mahal Directions](https://maps.app.goo.gl/4951P1Z6gEMirQ1Q6)
* **Background Wedding Melody:** Ambient audio toggle with Web Audio synthesizer fallback.

## 🚀 Getting Started

```bash

npm run dev

# Build for production

# Preview production build
```
